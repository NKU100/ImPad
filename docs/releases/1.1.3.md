# ImPad 1.1.3

## 更新内容

- 改进部分设备重启微信后需要重新登录的问题（#41）。模块不修改机型信息，而是在微信启动早期完成平板模式设置。
- 改善带热更新的微信版本的平板模式适配（#42）。
- 微信平板模式在小窗、分屏和切换屏幕分辨率后保持正常。

QQ 和企业微信的功能不变。

## 安装与升级

需要 Android 9 或更高版本、ARM64（`arm64-v8a`）、root，以及支持现代模块的 LSPosed。安装包沿用此前版本的签名，可直接覆盖升级。安装后在 LSPosed 中确认应用作用域，然后强行停止并重新打开对应应用。

首次启用模块或微信更新后，模块需要先识别一次，微信启动会稍慢；之后启动会更快。从 1.1.3-beta.1 升级时，由于不再使用联想平板机型信息，可能需要重新扫码登录一次。

## 适配说明

本次检查的微信版本为 8.0.80。应用更新后若无法正常使用，请反馈应用版本、问题现象及模块日志，便于排查。
