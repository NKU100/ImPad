# ImPad 1.1.0

相较于 [1.0.0](https://github.com/NKU100/ImPad/releases/tag/2-1.0.0)：

- 微信、QQ 和企业微信统一使用共享规则识别适配位置，移除旧 profile、descriptor 与历史安装包清单准入路径。应用更新后仍需重新验证兼容性。
- release 构建启用 R8，并仅打包 ARM64 原生库，大幅减小 APK 体积。
- 统一官方 APK 候选检查、固定静态回归和运行验收流程。
- 精简 README，明确安装要求与验证范围。

## 安装与升级

要求 Android 9 或更高版本、ARM64（`arm64-v8a`）、Root，以及支持 modern 模块的 LSPosed。32 位 ARM 和 x86 设备不在本版本支持范围内。

使用与 1.0.0 相同的正式签名，可覆盖安装。升级后在 LSPosed 中确认目标应用作用域，并强制停止、重新打开目标应用。

## 验证范围

无账号验收验证模块加载、适配行为和登录入口，不证明真实账号登录、服务端接受或双设备会话共存。应用版本与精确模块构建的验证记录应分别核对，不能由同源码的其他 APK 推定通过。
