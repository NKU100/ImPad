# ImPad 1.1.1

相较于 [1.1.0](https://github.com/NKU100/ImPad/releases/tag/3-1.1.0)：

- 支持官方微信 8.0.79（3200）的平板登录入口，保留微信 8.0.69（3040）的已验证适配。
- 加强微信规则匹配，校验平板判断结果的转发及其对登录入口可见性的影响，减少相似方法误匹配。
- 修复自动适配中的认证刷新、候选产物传递、构建校验和运行验收衔接问题。

## 安装与升级

要求 Android 9 或更高版本、ARM64（`arm64-v8a`）、Root，以及支持 modern 模块的 LSPosed。32 位 ARM 和 x86 设备不在本版本支持范围内。

沿用正式签名，可覆盖安装 1.1.0。升级后在 LSPosed 中确认目标应用作用域，并强制停止、重新打开目标应用。

## 验证范围

精确应用构建和模块身份见[已验证版本与验证范围](../support.md)。不同模块 APK 的验证结果不可互相替代。

无账号验收验证模块加载、适配行为和登录入口，不证明真实账号登录、服务端接受或双设备会话共存。应用更新或热补丁变化后仍需重新验证兼容性。
